# GigShield App

This is the mobile application for GigShield, built with Flutter.

## How to run
1. Open this folder in your terminal or IDE: `cd gigshield_app`
2. Run `flutter pub get` to download dependencies.
3. Hook up an Android emulator (API 21+).
4. Run `flutter run`.

## Tech Stack
- **Framework:** Flutter (Material 3)
- **Routing:** go_router (Navigator 2.0)
- **Target:** Android (Budget Devices)
